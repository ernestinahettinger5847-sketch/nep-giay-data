# Nếp Giấy · Media

Kho công khai chứa ảnh và video hướng dẫn mà ứng dụng Nếp Giấy tải theo đường dẫn trong catalog. File `media-manifest.json` ghi phiên bản, kích thước và SHA-256 cho từng tệp đã đăng.

Các đường dẫn của media giữ theo catalog. Khi thay video, kiểm tra lại thời gian từng bước. Cập nhật `remote-video-index.txt` trong app khi thêm hoặc gỡ video. Catalog, ảnh offline và tiến độ chơi được quản lý trong dự án Android.
